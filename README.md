# ⚽ Football Betting Assistant: Mercati Accessori 1X2

Web App interattiva sviluppata in **Python** con **Streamlit** per l'analisi statistica e il calcolo delle probabilità **1X2** sui mercati accessori del calcio (*Tiri in Porta, Calci d'Angolo, Ammonizioni, Fuorigioco e Falli*), includendo sia i principali campionati europei che le **Coppe Europee**.

## 🚀 Caratteristiche Principali
- **Calendario Partite Integrato**: Selezione rapida di partite ufficiali e giornate per Serie A, Premier League, La Liga, Champions League, Europa League e Conference League.
- **Filtri di Contesto Avanzati**: Filtri per campo (Casa/Trasferta) e tipologia di avversaria (Big, Medie, Piccole).
- **Modello Statistico (Poisson)**: Calcolo delle probabilità congiunte 1X2 basato sui tassi attesi degli eventi.
- **Interfaccia Moderna a Schede**: Dashboard pulita con previsioni, statistiche storiche e simulazioni.
